下载与你的 Mac 匹配的安装包：

- **Apple Silicon（M 系列芯片）**：选择文件名含 `arm64` 的 `.dmg`。
- **Intel 芯片**：选择文件名含 `x64` 的 `.dmg`。

打开 DMG，将 FrameDock 拖入“应用程序”后启动。无需安装 Node.js 或模型 CLI；首次使用请在设置中配置模型服务地址与 API Key。ComfyUI 服务及工作流依赖需自行准备。

`SHA256SUMS.txt` 提供安装包校验值。项目处于开发阶段，请备份重要作品；模型调用可能由所配置的服务收取费用。
