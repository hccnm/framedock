# 项目目录验收

- 桌面入口：新建本地项目支持已有内容的作品目录；「打开项目目录」读取已有 FrameDock 项目；项目或创作页菜单支持「另存到目录」。项目内创作页共用目录。
- 新项目文件结构：`.framedock/flowharbor.project.json` 与 `.framedock/media/<SHA256>.bin`。剧情、角色、素材和技能保持在作品根目录原位置。旧根清单与媒体继续原位读写，不迁移；双清单、已有内部数据或并发初始化拒绝覆盖。
- 项目名称：未手动改名时，选择目录默认填入目录名；再次选择目录跟随新目录名。用户手动改名后保留输入，创建使用该名称。
- 文件工具：`project_list_files` 逐层列目录，`project_read_file` 每次从磁盘读取最新 UTF-8 正文。内置 API 和 Codex 共用工具契约。主进程通过已保存创作页归属与受信目录绑定解析路径，不接收模型指定的作品根。
- 本轮固定创作页和目录绑定标识。切换页面仍可读取本轮原项目文件，但画布工具拒绝修改新页面；页面移入其他项目或另存更换目录后，旧绑定的文件请求拒绝并要求重新发起任务。待确认工具执行前再次检查页面归属，附件异步加载后也复查。
- 技能支持普通 `skills/`、`.agents/skills/`、`.claude/skills/` 中的 `SKILL.md` 和引用资料，按需读取。未实现项目技能自动加入选择器、全局安装、执行脚本、自动监听或改写剧情。
- 路径保护：拒绝绝对路径、越界、符号链接、应用内部数据、其他隐藏配置、非普通文件、二进制控制字符和非法 UTF-8；底层文件系统读取错误仅返回错误码，不回显绝对路径。
- 通过的针对性回归：桌面目录/存储/创建接口 12 项；Agent 会话、API 工具循环、引擎、MCP 与操作 44 项；前端文件工具、ComfyUI 与项目归属 16 项。覆盖中文及插件节点/连线 ID 原样往返、最新正文、技能引用、并发初始化、旧格式、双清单、目录变更拒读及切页拒绝误写。
- 浏览器使用独立预览和内存桌面桥接验证首次目录名回填、再次选目录跟随名称、手动改名后重选目录保留输入、创建导航、共享目录文案、最新正文读取和跨页误写拦截。截图见 `shared-project-directory/custom-name.jpg`；没有触发真实原生选择器，也没有读写用户作品目录。验收后已移除内存桥接并重新加载独立预览页面。预览未启动 Agent sidecar，控制台连接拒绝属于该隔离环境；开发服务无编译错误。
- 保存失败保留错误与重试入口；退出握手等待画布和视口保存。未变化项目跳过写入，但仍检查磁盘清单和媒体。跨目录移动采用先目标后来源，不能保证多个目录的整体事务。
- 未执行构建、类型/语法检查，未重启用户 Electron；真实 NAS 挂载卷、原生选择器、大媒体和真实模型端到端仍待实测。初始化失败保留 `.framedock/initializing` 和部分文件，后续创建拒绝覆盖，需要确认残留内容后处理；不自动删除用户目录文件。独占清单发布使用文件系统硬链接，NAS 对该操作的支持尚未验证。
