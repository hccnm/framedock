# FrameDock 桌面基座迁移

## 已确定的产品边界

- 当前目录使用本机 infinite-canvas 的源码作为新基座，保留其 MIT 许可证、作者信息和前端归属标识。
- MiniMax Design 是页面组织、视觉和交互参考；不分发其专有代码或品牌素材。
- 现有桌面数据按 FrameDock 命名一次性迁移，保留项目、媒体、配置与对话；不自动导入相邻历史备份或上游应用数据。
- 项目是收纳多个创作页的容器；创作页拥有画布与对话。参见根目录 GLOSSARY.md。
- 桌面一次启动，应用内配置模型即可使用开源 Agent，不要求额外安装插件或模型 CLI。
- 项目与媒体存本机文件，桌面配置以 `storage/config.json` 保存，API Key 和 WebDAV 密码明文保存，不依赖系统钥匙串。旧加密文件保留但不自动导入，已有渠道需重新填写。
- 首版只开放随应用提供的插件，不开放任意 URL 执行插件。

## 基座与备份

源目录为相邻 infinite-canvas，复制其当前工作树源码（包含尚未提交的桌面与ComfyUI实现），共554个文件。未复制.git、node_modules、构建产物、用户数据或环境凭据。

原应用内容完整保留在相邻历史备份目录，包括已收集技能与插件包；这些内容没有导入新应用。当前仅保留会话工具配置目录，预览入口已改为新基座。
