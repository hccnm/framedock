# Contribute to the Project

You can support this repository by reporting reproducible problems and improvement suggestions through [Issues](https://github.com/hccnm/framedock/issues), or by submitting code and documentation through [pull requests](https://github.com/hccnm/framedock/pulls).

The [contributing guide](https://github.com/hccnm/framedock/blob/main/CONTRIBUTING.md) is the source for development setup, verification commands, PR requirements, and review expectations. The repository provides bug report, feature request, and PR templates. PR CI checks frontend types, frontend and Agent tests, desktop tests, plugin SDK types, and application compilation. Real-service, native-interaction, and installer verification must be reported separately.

Include the relevant version, environment, and reproduction steps when reporting a problem. For security vulnerabilities, follow the [security reporting guide](/docs/support/security) instead of publishing sensitive details.
