# 参与贡献

欢迎通过本仓库的 [Issue](https://github.com/hccnm/framedock/issues) 提交可复现的问题和改进建议，或通过 [PR](https://github.com/hccnm/framedock/pulls) 贡献代码和文档。

开发环境、验证命令、PR 要求与审查流程统一维护在[贡献指南](https://github.com/hccnm/framedock/blob/main/CONTRIBUTING.md)。仓库提供问题反馈、功能建议和 PR 模板；PR 基础 CI 检查前端类型、前端与 Agent 测试、桌面测试、插件 SDK 类型及应用编译。真实服务、原生交互与安装包验收需要另行说明，不由基础 CI 代替。

反馈问题时，请附上相关版本、运行环境和复现步骤。安全漏洞请遵循[漏洞提交说明](/zh-CN/docs/support/security)，不要公开敏感细节。
